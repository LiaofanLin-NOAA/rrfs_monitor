Disclaimer: These are personal notes on the GSL/AVID RRFSv2 prototype real-time experiments and related resources. They are not an official project description.

RRFSv2 Real-time Prototype Experiments

  • RRFSv2X: The baseline real-time prototype, including both deterministic and ensemble runs.
  • RRFSv2b: Similar to RRFSv2X, with both deterministic and ensemble runs, but focused on testing atmospheric blending.
  • RRFSv2c: Based on RRFSv2X, but currently running only the deterministic configuration and using background-error covariance from the RRFSv2b ensemble. This experiment focuses on testing the Noah-MP land surface model (LSM).
  • RRFSv2s: Based on RRFSv2X, with a focus on smoke and dust. More details will be added.
