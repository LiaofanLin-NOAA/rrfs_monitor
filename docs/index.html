RRFSv2X · Ensemble monitoring

Ensemble Variable Monitor (Near Real Time)

RRFSv2X is the current real-time prototype of the Rapid Refresh Forecast System Version 2 (RRFSv2), running at NOAA’s Global Systems Laboratory (GSL) on NOAA high-performance computing (HPC) systems. Learn more on the GSL RRFS website and view the RRFSv2X forecast graphics. This site provides near-real-time monitoring of RRFSv2X ensemble statistics, particularly near-surface and land-surface variables, to help assess ensemble stability. Monitored variables include 2-m temperature, 2-m specific humidity, layer-1 soil moisture, and layer-1 soil temperature. Selected ensemble spread maps are available via Google Drive.
